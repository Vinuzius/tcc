ℹ️ Sobre o Sistema & Requisitos Atendidos

Trabalho de Conclusão de Curso — Controle de Visibilidade e Privacidade de Dados em Consultas SQL

🎯 Objetivo do Projeto

Controlar a visibilidade e o tratamento dos dados disponibilizados aos usuários durante consultas a um banco de dados, aplicando mecanismos de proteção baseados em políticas de privacidade e legislações vigentes (LGPD, GDPR).

🔐 Autenticação OAuth 2.0

Autenticação segura padrão RFC 6749 (Password Bearer Flow e simulação de Provedores OAuth 2.0 como Google e GitHub), com geração de JWTs e validação de tokens nas rotas da API.

👥 CRUD de Usuários & Perfis

Cada usuário possui login, senha criptografada com bcrypt e um perfil de privacidade associado. Regra de ouro: Apenas o administrador possui a prerrogativa de definir e modificar o perfil dos usuários.

⚡ Executor de SQL & Admin

Execução de consultas SQL read-only com feedback visual imediato em tabela responsiva. Na tela de administração, o perfil de cada usuário pode ser modificado com base no resultado dinâmico de select p.name from perfil.
